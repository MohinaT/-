# Лабораторная работа 1.1 - Площадь треугольника

## Формулировка задания
Написать программу, которая вычисляет площадь треугольника по трём его сторонам (по формуле Герона) с точностью до сотых.

## Инструкция по использованию

1. Ввести длины сторон треугольника.
2. Нажать кнопку «Рассчитать».
3. Получить площадь треугольника.

Задание 2. Конвертер расстояний

Формулировка задания

Создать программу-конвертер расстояний с поддержкой километров, метров, сантиметров, миллиметров, миль и ярдов.

Среда разработки

Python 3.13

Библиотека графического интерфейса Tkinter.

Запуск программы

Открыть папку "DistanceConverter" и запустить файл:

python converter.py

Использование

1. Ввести значение.
2. Выбрать исходную единицу измерения.
3. Выбрать целевую единицу измерения.
4. Нажать кнопку «Конвертировать».
